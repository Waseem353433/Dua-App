# Dua-App
🤲 Dua Application
📌 Project Description

This is a simple Dua Application built using HTML, CSS, and JavaScript.
The app displays different duas (supplications), and each time the user clicks a button, a new dua is shown on the screen.

🚀 Features
🤲 Display random duas
🖱️ Button to show a new dua
⚡ Instant update using DOM manipulation
🧾 Simple and clean interface
🛠️ Technologies Used
HTML – Structure of the app
CSS – Styling and layout
JavaScript – Logic and DOM manipulation
